# IS31FL3730-QFLS2-EB — driving from an MSP430 LaunchPad

Notes for controlling the ISSI/Lumissil **IS31FL3730** LED matrix driver eval board from
an MSP430 LaunchPad. See bench inventory in [DEV_BOARDS.md](DEV_BOARDS.md).

Source: [IS31FL3730 Evaluation Board Guide (Rev. B, 11/2025)](https://www.lumissil.com/assets/pdf/core/IS31FL3730_EB.pdf)
· [IS31FL3730 datasheet](https://www.lumissil.com/assets/pdf/core/IS31FL3730_DS.pdf)

## Eval board control model

The board is self-contained: LDO (U2, PAM3101), onboard demo MCU (U3, NXP LPC922),
audio amp (U4), and the IS31FL3730 (U1).

- **JP1 closed (default):** onboard MCU drives the IS31FL3730 — 6 built-in demo modes.
- **JP1 open:** onboard MCU stops, its I²C pins go **high-impedance**. Drive the chip
  externally via **TP3**. ← use this for MSP430 control.
- **K1 = MODE button:** cycles the 6 demo modes. Only active when JP1 is closed. Ignore
  it once JP1 is open.

## Onboard I²C pull-ups — do NOT add your own

- **R1, R2 = 4.7 kΩ** are the SDA/SCL pull-ups, tied to the board's own 3.3 V rail (U2).
- They stay connected regardless of JP1 — opening JP1 only high-Z's the MCU's lines.
- So: power the eval board from its own supply and **do not add external pull-ups**.
- **R3 = 100 kΩ pulls SDB to GND** (Fig. 2) → the driver is in **shutdown by default**; SDB
  must be driven **high** to enable it. **AD is hardwired to GND** → fixed I²C address
  **0x60**. (R4 = MODE-button pull-up on the demo MCU; R5/R6 = 20 k/39 k → audio side.)

## Recommended wiring (external control)

Power the eval board from its **own USB/supply**, then connect only signals + ground to
the LaunchPad — no LED current flows through the LaunchPad this way.

| Eval board (TP3) | MSP430 LaunchPad (FR2476 or FR2433) | Notes |
|---|---|---|
| SDA | P1.2 / UCB0SDA (BoosterPack J1.10) | I²C data |
| SCL | P1.3 / UCB0SCL (BoosterPack J1.9)  | I²C clock |
| GND | GND (J2.20)                         | **must** be shared |
| SDB | **required** — any GPIO, drive **HIGH** | active-low shutdown, pulled LOW by R3 → must drive high to enable the driver |

- Both LaunchPads use **eUSCI_B0** with the same pins (40-pin BoosterPack standard).
- FR24xx run at 3.3 V → no level shifting needed.
- **TP3 pins** are individually silk-labeled **SDB / SCL / SDA / GND** (schematic Fig. 2 numbers
  them 1=GND, 2=SDA, 3=SCL, 4=SDB) — no ambiguity, they're labeled per-pin on the board.
- If you instead power the board's VCC from the LaunchPad 3V3, keep brightness low — a
  full matrix can exceed the eZ-FET LDO's budget.

## Firmware quick reference

- I²C address: **0x60** (7-bit) — AD is strapped to GND on this board (Fig. 2). AD selects
  `0b11000_AA`: GND=0x60, SCL=0x61, SDA=0x62, VCC=0x63. (**0x74 is the IS31FL3731**, a
  different chip — not this one.) Datasheets saved at [../../msp-fw/datasheets/](../../msp-fw/datasheets/).
- Minimal write sequence: config `0x00 ← 0x00` (8×8, on) → brightness `0x19 ← 0x10` →
  frame bytes to `0x01` → poke `0x0C` to latch.
- Register-level reference driver: <https://github.com/jbkim/IS31FL3730>
